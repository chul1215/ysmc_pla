## 1. 요약 (Executive Summary)

### 핵심 결론 4가지

1. **대전 미용 의원 10곳 중 외국인 마케팅을 능동적으로 운영하는 곳은 페이스성형외과 단 1곳**. 영·중·일·태·러 5개 다국어 사이트(`en/cn/jp/th/ru.faceps.com`)를 보유. 닥터스미·미래·숨은그림·희소·비포애프·갤러리·뉴진·올웨이즈윤대영·오체안 대전점은 다국어 사이트 미운영 또는 메뉴 텍스트만 표시(실제 콘텐츠 없음).

2. **대전 3개 대학병원 모두 국제진료센터 보유**. 충남대·건양대는 명시적 코디네이터·통역(영·중 또는 영·중·러) 운영, 을지대는 사이트 다국어(KOR/ENG/CN/JP) 진입은 있으나 별도 외국인 패키지 안내 페이지 노출이 약함. **세 병원 모두 성형외과 단위의 외국인 환자 패키지(미용·재건)는 별도로 패키징하지 않은 상태**.

3. **대전 지역 자체가 외국인 환자 유치에서 비중 미미**. 2024년 한국 방문 외국인환자 117만명 중 서울이 85.4%를 점유, 대전을 포함한 지방은 통계상 별도 항목으로 잡히지 않을 정도(부산 2.6%, 제주 1.9% 수준). 즉 **대전은 블루오션이지만 시장 자체가 작다.**

4. **2025년말 외국인 미용 성형 부가세 10% 환급제도 종료**가 확정되어 2026년부터 가격 경쟁력 약화 국면. 신규 진입자(유성선병원)가 부가세 환급을 가격 무기로 쓸 시간은 사실상 끝났고, **"안전·정확 진단·종합병원 인프라"라는 비가격 차별화**가 상수가 되는 시점.

### 유성선병원이 취해야 할 포지션 한 줄 요약

> "**대전·세종·충청권 거주 일본인·중국인·러시아인 직장인/유학생 + 대학병원 협진이 필요한 외상·재건 외국인 환자**"를 1차 타겟으로 잡고, 강남식 미용 마케팅이 아닌 **신뢰·안전·통역 기반의 종합병원 어프로치**로 진입한다.

## 2. 한국 외국인 환자 시장 배경 (제도·통계)

### 2.1 2024년 시장 규모 (KHIDI / 보건복지부)

| 항목 | 수치 | 비고 |
|------|------|------|
| 외국인환자 수 | **117만 467명** | 2023년 60만5천768명 대비 +93.2% (2009년 사업 시작 이래 최대) |
| 진료과 1위 | **피부과 56.6% (70.5만명)** | 전년 대비 +194.9% 폭증 |
| 진료과 2위 | **성형외과 11.4%** | |
| 진료과 3위 | 내과통합 10.0% | |
| 국가 1·2위 | 일본+중국 60.0% (70.2만명) | |
| 국가 3·4위 | 미국 8.7%, 대만 7.1% | |
| 지역 1위 | **서울 85.4% (100만명)** | |
| 기타 지역 | 경기 4.4%, 부산 2.6%, 제주 1.9% | **대전은 별도 항목 없음** |
| 의료기관 종별 | **의원급 82.0%** | 전년 대비 +138.4% |

→ **시사점**: 외국인 환자 시장은 사실상 "서울 의원급 피부과" 중심으로 수렴. 대전 종합병원이 동일 시장에서 직접 경쟁하기보다는 **(a) 대전·세종·충청권 거주 외국인** 또는 **(b) 의원급이 못 다루는 외상·재건/조직검사 동반 미용** 같은 차별 카테고리를 노려야 함.

### 2.2 핵심 제도 3종

#### A. 외국인환자 유치 의료기관 등록제 (의료법 → 의료해외진출법으로 이관)

- 외국인환자를 유치하려는 의료기관은 시·도지사에게 **등록 의무** (외국인환자유치 정보시스템 medicalkorea.or.kr/korp 통해 신청)
- 진료과목별 전문의 1명 이상 보유, 의료사고 보상 보증보험 의무 가입
- 매년 2월말까지 전년도 유치실적 보고 의무
- 2024년 기준 등록 의료기관 약 6,364건(공공데이터포털 KHIDI 데이터, 2025-07-22 기준)

#### B. 외국인환자 유치의료기관 평가인증제(KAHF) — 2024년부터 본격 시행

- 보건복지부 + KHIDI 주관, **지정제(2년) → 인증제(4년)**로 2023년 12월 개정
- 2023년 첫해 **13개 기관** 인증 (대전 지역 인증기관 명단은 별도 확인 필요)
- 인증 혜택: 인증마크 사용권, 국내외 홍보회 참가지원, **법무부 의료관광 우수유치기관 당연지정**, 외국인환자 유치 운영자금 융자, 정부지원사업 가점

#### C. 외국인환자 미용성형 부가세 환급제도 — 2025년말 종료 확정 ⚠️

- 2016년 도입, 정부지정 의료기관에서 외국인이 쌍꺼풀·코·치아미백·여드름 치료 등 미용 시술 시 **10% VAT 환급**
- 환급 규모: 2021년 약 8억원 → **2024년 약 9,550억원** (3년만에 119배)
- 2025년 12월 31일 종료 확정. 2026년부터는 환급 불가
- **유성선병원 시사점**: 환급 게임은 늦었음. 가격 무기가 아닌 **안전·정확 진단** 기반 메시지로 진입해야 함

### 2.3 외국인 수가의 합법성 (Q&A)

**Q1. 외국인에게 내국인과 다른 수가 적용이 합법인가?**
→ **합법**. 2009년 의료법 개정으로 외국인환자 영리적 유치가 법제화됨. 비보험·비거주 외국인 대상 "국제수가"는 의료기관이 자율 책정 가능. 다만 등록 외국인·국내 거소신고자는 국제수가 대상에서 제외.

**Q2. 부가세 환급 종료 후 미용 성형 외국인 단가 매력도는?**
→ 2026년부터 10% 가격 경쟁력 상실. 일본·중국 환자가 "한국이 더 이상 싸지 않다"고 인식할 가능성. 가격이 아닌 **기술·안전·후기**로 차별화 필요.

**Q3. 종합병원이 의원 대비 가지는 제도적 강점?**
→ ① 마취과·중환자실·응급실 보유로 **합병증 대응 인프라**, ② 평가인증제(KAHF) 평가 항목인 "안전 시스템" 점수 우위, ③ 비자 발급 시 외국인 환자가 종합병원을 더 신뢰함 (특히 러시아·중앙아시아·중동), ④ 보건복지부의 "외상·재건" 카테고리 정책지원 매칭 가능성.

### 5.2 KAHF 평가인증 vs. 단순 등록 — 의사결정

- **단계 1 (필수)**: 보건복지부 외국인환자 유치 의료기관 **등록** (medicalkorea.or.kr/korp 신청)
- **단계 2 (12~24개월 후)**: KAHF 평가**인증** 도전. 4년 유효, 법무부 우수유치기관 당연지정, 정부 홍보회 참가지원 — 종합병원의 강점인 안전 시스템이 평가 항목에 직접 매칭되어 의원급 대비 유리
- 둘은 별개. 등록만 해도 외국인 진료는 가능하나, 인증을 받으면 **마케팅 신뢰도와 정부 채널 접근성이 달라짐**

### 5.3 부가세 환급 종료 후 (2026~) 가격 전략

- 환급 종료로 일본·중국 환자는 한국 미용 시술의 가격 매력도가 약 10% 하락한 것으로 인식할 수밖에 없음
- 종합병원이 이 시점에 **"부가세 환급 없이도 안전·정확 진단·합병증 대응에서 차별"**이라는 메시지를 선점하면, 강남 의원과 다른 트랙으로 성장 가능
- 단, **국제수가**(외국인 별도 수가)는 합법이므로 통역·코디네이터·픽업 비용을 패키지화한 수가표를 별도로 운영 가능. 대전 다른 의원이 못 만들고 있는 영역.

### 5.4 단계별 12개월 로드맵 (외국인 영역만)

| 시기 | 액션 |
|------|------|
| **Phase 0 (개설 직후)** | 보건복지부 외국인환자 유치 의료기관 등록 신청, 영문 진단서·동의서 5종 표준화, 영·중 통역 위탁 1~2명 확보 |
| **Phase 1 (3~6개월)** | 영문·일문 사이트 미니 버전(메인 + 진료과 + Contact), 라인 공식 계정, 카카오톡 영문 응대 매뉴얼, 외국인 학생증 할인 정책 |
| **Phase 2 (6~9개월)** | 샤오홍슈 시범 운영 1~2개월, 대전 컨소시엄(충남대 사례 참조) 참여 검토, KAIST·충남대 외국인 학생회 협력 행사 1회 |
| **Phase 3 (9~12개월)** | KAHF 평가인증 사전 컨설팅, 건양대 미커버 영역(러시아어 성형 패키지) 자체 운영 검토, 누적 외국인 환자 30명 목표 |

### 5.5 절대 하지 말아야 할 것

1. **강남식 가격 경쟁 마케팅 모방** — 시장이 다르고, 부가세 환급 종료로 가격 게임 자체가 끝남
2. **다국어 사이트만 만들고 통역·코디네이터 없이 방치** — 페이스성형외과 영문 사이트 인증서 만료 사례가 반면교사. 콘텐츠보다 응대 인력이 먼저
3. **종합병원 인지도만 믿고 SNS 미운영** — 외국인은 SNS·구글·인스타·샤오홍슈에서 1차 검색. 사이트 가기 전에 SNS에서 신뢰가 형성되어야 함

### 6.4 보고서가 다루지 못한 영역 (스코프 한계)

1. **medicalkorea.or.kr/korp 등록부 직접 조회** — 13개 병원 각각의 KHIDI 등록 여부와 등록일자, 진료과목 필터 결과는 본 보고서에서 1건도 직접 확인하지 못함. **다음 라운드의 첫 작업은 이 등록부 다운로드와 대전 지역 필터링**.
2. **각 병원 인스타그램·블로그의 실제 외국인 응대 게시물** — 사이트만 본 결과. 실제로는 "직원 한 명이 영어 가능"이라는 식의 비정형 운영이 SNS에서만 노출되는 경우가 흔함.
3. **에이전시 제휴 여부** — 의료관광 에이전시는 사이트 푸터에 표기하지 않는 경우가 더 많음. 강남구 메디컬투어센터 같은 지자체 차원 등록부 확인이 별도 필요.
4. **대전 컨소시엄의 정확한 명칭과 참여 의료기관 명단** — 충남대 페이지에서 "대전광역시 컨소시엄" 표기만 확인. 이 컨소시엄이 KOMTC인지, 대전관광공사 산하인지, 어느 의료기관이 참여하는지는 추가 조사 필요.
5. **페이스성형외과 외 의원의 "과거 외국인 마케팅 시도 흔적"** — 인스타그램 영문 캡션, 블로그의 영문 게시물 같은 비정형 활동은 본 조사에서 다루지 않았음.
6. **대전 세브란스, 가톨릭대전, 대전성모 등 본 보고서 비대상 병원의 국제진료** — 본 조사는 선행 보고서의 13개 경쟁사 명단을 기준으로 했으므로, 대전 시내 다른 종합병원의 국제진료 운영은 비교 영역 밖.

### 6.5 가장 위험한 단정 한 줄 — 사용 시 주의

> "대전 미용 의원 중 페이스만 다국어 운영"

→ 이 문장은 닥터스미·숨은그림·올웨이즈윤대영 3곳을 fetch 실패로 직접 확인하지 못한 상태에서의 단정이므로, **"공개 사이트에서 확인된 범위에서는 페이스만"**으로 표현 완화를 권장. 위 본문에는 "확인되지 않음"으로 처리해 두었으나, 의사결정 회의에서 "닥터스미는 안 한다"라고 단정 인용되지 않도록 주의 필요.

1. **medicalkorea.or.kr/korp 외국인환자 유치 의료기관 등록부에서 "대전 + 성형외과" 필터 조회** — 누가 등록되어 있고 누가 안 했는지 30분 안에 확정 가능.

## 8. 심층 분석: 왜 대전 성형외과는 외국인 마케팅을 하지 않는가

| 페이스가 "5개국 다국어"를 만든 게 2010년대 후반 초기 K-뷰티 붐 시점 추정 → 현재는 ROI가 안 맞아 방치 | §7.4 (구등록 폐업 + 현 등록 유지의 모순적 패턴) |

**반증 시도**: "그러면 비포애프·뉴진은 왜 7개국·6개국을 신고했나?"
→ **신고는 무료**. 신고 대상국가는 단순 신고일 뿐 실제 마케팅·인프라 투자와는 무관. 비포애프·뉴진이 7개국·6개국을 신고했지만 다국어 사이트는 없는 게 그 증거. **신고는 비용 ≈ 0, 실제 마케팅은 비용 多** → 신고는 적극, 마케팅은 미적극의 갭이 한국 의원의 일반 패턴.

**신뢰도**: ★★★★☆ (페이스 사례가 반면교사)

#### 가설 6. 대체재 가설 — "한국어 환자만으로도 둔산동 의원 8곳이 충분히 먹고산다"

| 근거 | 출처/데이터 |
|------|-----------|
| 대전 인구 144만 + 충남·세종·청주 광역권 약 700만 → 한국어 환자 풀이 의원 8곳 부양에 충분 | 행정안전부 인구 통계 |
| 둔산동 의원들은 대부분 1인 전문의 의원 — 외국인 신규 시장 개척 인센티브가 운영자 1인의 시간 비용 대비 낮음 | 본 보고서 §2 (선행) |
| 카카오톡 채널·강남언니·바비톡으로 한국 환자 신규 유입이 안정적 | 본 보고서 §3 |

**반증 시도**: "그러면 1인 의원이 아닌 닥터스미(전문의 3인)가 등록 후 폐업한 이유는?"
→ 닥터스미가 등록 후 폐업한 사실은 **"한 번 시도했지만 ROI가 안 났다"**는 가설 5의 근거에 더 가까움. 즉 가설 5와 가설 6은 **결합 가설** ("국내 환자 풀이 충분 + 외국인 추가 ROI는 음수"). **결합형으로 강한 가설**.

**신뢰도**: ★★★★☆

#### 가설 7. 의료광고 규제 가설 — "의료법이 SNS 마케팅을 강하게 제한"

| 근거 | 출처/데이터 |
|------|-----------|
| 의료법 제56조 의료광고 금지·제한 사항: 비교 광고, 환자 유인, 치료 효과 보장, 전후사진 등 | 의료법 |
| 외국인 대상 SNS도 한국 의료법 적용 — 인스타그램 외국어 게시물도 의료광고심의 대상 | 보건복지부 가이드라인 |
| 강남 대형 의원조차 의료법 위반 행정처분 사례 다수 | 의료광고심의 결과 공시 |

**반증 시도**: "의료법은 전국 동일한데 왜 강남은 적극적이고 대전은 안 적극인가?"
→ 의료법은 동일하지만 **강남은 의료법 리스크를 감수할 ROI가 있고 대전은 없음**. 즉 의료법은 "공통 제약 조건"일 뿐 차별 변수는 아님. **가설 자체는 일부 사실이지만 차별 설명력 약함**. 단, **종합병원이 의원보다 의료법 리스크에 더 보수적**이라는 측면에서는 본 가설이 종합병원의 미적극을 부분 설명.

**신뢰도**: ★★☆☆☆ (공통 제약, 차별 설명력 낮음)

#### 가설 8. 종합병원 특수성 가설 — "대전 대학병원은 미용보다 재건·검진 중심"

| 근거 | 출처/데이터 |
|------|-----------|
| 충남대·건양대·을지대 모두 [유지] 등록 + 신고 국가 다양 (충남대 7개국, 건양대 4개국) | §7.4 |
| 그러나 사이트 분석 결과 **성형외과 외국인 패키지는 0** — 미용 영역 마케팅 자체가 의도적 부재 | 본문 §3.11~§3.13 |
| 대학병원의 외국인 진료는 종합검진 + 암 진료 + 재건 영역에서 활동, 미용은 의도적 회피 | (관행) |

**반증 시도**: "그러면 대학병원은 외국인 마케팅을 하긴 하는데 성형 영역만 안 하는 것?"
→ **정확.** 충남대·건양대는 외국인 환자 받음 (검진·재건). 단 성형외과는 종합병원 내부에서도 미용 마케팅에 보수적임 (의료광고 리스크, 공공 의료기관 정체성). 따라서 "대전 성형외과 외국인 마케팅 부재"는 **(a) 의원급의 ROI 회피 + (b) 대학병원의 미용 영역 의도적 회피**라는 두 트랙의 결합.

**신뢰도**: ★★★★☆

### 8.3 통합 결론 (한 단락)

> 대전 성형외과가 외국인 마케팅을 하지 않는 이유는 **"수요(가설1) × 인프라 비용(가설5) × 대체재 충분(가설6)"의 곱셈이 마이너스**이기 때문이다. (a) 한국 외국인 의료관광 환자의 99%+가 서울에 집중 → 대전 시장 자체가 거의 없음. (b) 다국어 사이트·통역·코디네이터 인프라는 의원 1인 운영에서 회수 불가능한 비용. (c) 한국어 환자 풀(대전+충청권 700만)만으로 둔산동 8곳이 안정적으로 운영됨 → 외국인 신규 시장에 진출할 인센티브 부재. 부가세 환급 종료(가설4)나 의료광고 규제(가설7)는 부수적 제약일 뿐, **결정적 변수는 시장 규모와 ROI**. 페이스성형외과의 5개국 다국어 사이트가 SSL 인증서 만료된 채 방치된 사례가 이 결론의 가장 명확한 반면교사다.

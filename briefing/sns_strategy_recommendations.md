## 1. 포지셔닝 전략

### 1.1 독점 포지션 정의

두 보고서를 교차하면 유성선병원이 점유 가능한 포지션이 명확하게 도출된다.

```
@days_harada 모델  = 단일 시술 깊이 (쌍꺼풀 절대 전문가)
대전 경쟁사 모델   = 넓이 (다양한 미용 시술, 얕은 SNS)
유성선병원 모델    = 종합병원 안전 + 미용성형 + 치료재건
```

**경쟁사가 절대 따라올 수 없는 3가지:**

1. "수술 중 응급상황 시 종합병원 전체가 백업한다"는 메시지 (닥터스미가 한 줄 언급, 콘텐츠로 심화한 곳 없음)
2. 외상·화상·종양 치료 콘텐츠 (인스타그램에서 완전 공백, 오체안은 유튜브에서만)
3. 보건복지부 장관 표창·대한공중보건의사협의회 회장 이력 (대전 전체 경쟁사 중 유일)

### 1.2 경쟁 포지셔닝 맵

| 경쟁자                   | 역할                             | 유성선 대응 방향                             |
| ------------------------ | -------------------------------- | -------------------------------------------- |
| **뉴진성형외과**   | SNS 벤치마크 대상 (22,500팔로워) | 릴스 품질·스토리텔링 동등 수준 달성         |
| **비포애프**       | 팔로워 9,366명, 참여율 0.1%      | 콘텐츠 품질로 참여율 역전 (3.5%+ 목표)       |
| **닥터스미**       | 안전 메시지 일부 선점            | 안전 콘텐츠 심화로 차별화                    |
| **희소성형외과**   | "섬세함" 슬로건 유사             | "대학병원의 안전함에 섬세함을 더하다"로 분리 |
| **올웨이즈윤대영** | 유성구 유일 개원의               | 종합병원 vs 개원의 포지션 차이 강조          |

### 1.3 핵심 메시지 체계

| 레벨          | 메시지                                | 적용                    |
| ------------- | ------------------------------------- | ----------------------- |
| **1차** | "대학병원의 안전함에 섬세함을 더하다" | 모든 콘텐츠 브랜드 코어 |
| **2차** | "수술실 뒤에 종합병원이 있습니다"     | Credibility 게시물 전용 |
| **3차** | "일상의 상처부터 섬세하게"            | 치료재건 게시물 전용    |

## 2. 계정 설계

### 2.1 계정명 및 바이오

**계정명**: `@ysmc_plastic` (추천)

- 병원 약칭(ysmc) + 진료과 조합으로 검색 최적화
- 종합병원 소속이라는 최대 차별점을 계정명에서 시각화

**바이오 (최종안):**

```
대전 유성선병원 성형외과
대학병원의 안전함에 섬세함을 더하다
신정환 과장 | 성형외과 전문의
가톨릭중앙의료원 출신 | 보건복지부 장관 표창
눈 · 리프팅 · 쁘띠 · 외상 · 재건
```

**바이오 설계 원칙:**

- 1행: 공식 병원명 (신뢰)
- 2행: 브랜드 슬로건 (차별화)
- 3·4행: 담당의 이름·자격·객관적 경력 (전문성·사회적 증거)
- 5행: 진료 영역 나열 (검색 + 서비스 범위 안내)

**멀티링크 구성 (linktree 또는 lit.link):**

1. 전화 상담 `tel:042-000-0000`
2. 진료 예약 `booking.html`
3. 카카오톡 상담 채널
4. 네이버 예약
5. 공식 웹사이트
6. 오시는 길 (네이버 지도)

## 3. 콘텐츠 전략

### 3.1 콘텐츠 4C 프레임워크

| 카테고리              | 비율 | 정의                                      | 대전 공백 연동                                                  |
| --------------------- | ---- | ----------------------------------------- | --------------------------------------------------------------- |
| **Clinical**    | 35%  | 시술 정보·교육형 콘텐츠                  | 페이스가 교육형 시도하나 팔로워 전환 실패 — 영상 품질로 차별화 |
| **Credibility** | 30%  | 안전 시스템·의료진 경력·종합병원 인프라 | **대전 전체 완전 공백 — 최우선 선점 영역**               |
| **Case**        | 20%  | B/A 결과 (심의 통과분)                    | 뉴진·비포애프 활발하나 "안전한 환경에서의 결과"는 없음         |
| **Community**   | 15%  | 환자 Q&A·댓글 소통                       | 대전 경쟁사 전반 소통형 콘텐츠 부재                             |

### 3.2 게시물 유형별 비율

| 유형                           | 비율 | 역할                                  | 빈도       |
| ------------------------------ | ---- | ------------------------------------- | ---------- |
| **Reel** (30~60초)       | 40%  | 바이럴 트리거, 알고리즘 도달 극대화   | 주 2회     |
| **Carousel** (슬라이드)  | 30%  | 교육형 정보 전달, 저장(Save) 유도     | 주 1~2회   |
| **Single Post** (이미지) | 15%  | B/A, 의료진 소개, 시설 사진           | 주 1회     |
| **Story**                | 15%  | 일상 소통, 실시간 업데이트, 투표·Q&A | 매일 1~2개 |

> **하라다 vs 한국 차이:** 하라다는 Post 83% / Reel 17%이나, 한국 인스타그램은 Reel 우선 노출이 강하고 뉴진성형외과의 22,500명 팔로워도 릴스 전략의 결과. Reel 비중을 40%로 설정 (하라다의 2.4배).

### 3.3 게시 빈도 단계별 계획

| 단계                          | 기간             | 빈도                                              | 근거                                  |
| ----------------------------- | ---------------- | ------------------------------------------------- | ------------------------------------- |
| **Phase 0** (사전 준비) | 진료 개시 4주 전 | 선제작 15개 완료                                  | 3×3 그리드 + 버퍼                    |
| **Phase 1** (론칭기)    | 1~4주            | 주 5~7개 (Week 1: 월~금 5개, Week 2~4: 매일 1개) | 알고리즘 학습 기간 집중 투자          |
| **Phase 2** (성장기)    | 5~8주            | 주 5~6개                                          | 뉴진성형외과(주 2~4회) 대비 우위 유지 |
| **Phase 3** (안정기)    | 9~12주           | 주 4~5개                                          | 콘텐츠 품질 유지와 지속 가능성 균형   |

Story는 모든 단계에서 매일 1~2개 유지.

여러분은 어떤 점이 가장 궁금하셨나요? 댓글로 알려 주세요.

## 7. 대전 경쟁사 대비 차별화 실행 포인트

### 7.1 뉴진성형외과 비대칭 전략

뉴진은 팔로워 수 경쟁 대신 아래 3가지 비대칭으로 접근:

### 7.2 비포애프 교훈 (반면교사)

- 팔로워 9,366명에 참여율 0.1% — 팔로워 수 경쟁의 함정
- 유성선병원은 **콘텐츠 품질과 참여율(3.5%+)에 집중**, 팔로워 수 추월은 목표 아님
- 500명의 진짜 관심 팔로워 > 9,000명의 비활성 팔로워

**한국은 일본과 달리 B/A 게시에 의료광고 사전심의 의무.**

| 단계              | 원칙                                                    |

- 심의번호
- "개인에 따라 결과가 다를 수 있으며, 부작용이 발생할 수 있습니다"
- 수술 후 주의사항
- 촬영 시점 (수술 후 경과 기간)

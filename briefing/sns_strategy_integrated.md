## 1. 분석 요약

### 1.1 @days_harada에서 배울 것 3가지

**첫째, 캡션 시스템화가 브랜드를 만든다.**
@days_harada의 6-Zone 캡션 템플릿은 매일 게시해도 브랜드 메시지가 흐트러지지 않는 구조적 안전장치다. 77,000명 팔로워 달성의 배경에는 "매번 다른 시술, 매번 같은 철학"이라는 반복이 있다. 유성선병원도 캡션 템플릿을 먼저 설계하고 콘텐츠를 생산해야 한다.

**둘째, Reel은 바이럴 트리거, Post는 신뢰 축적이다.**
Post(이미지) 83% 대 Reel 17%인데도 Reel이 좋아요 3.2배, 댓글 2.4배를 기록한다. 역대 최고 Reel은 9,600좋아요로 Post 최고의 90배다. 그러나 매일 올리는 Post가 "이 의사는 매일 수술한다"는 잠재 메시지를 전달하며 신뢰를 쌓는다. Reel과 Post는 대체재가 아니라 분업 관계다.

**셋째, 서브계정 분리는 전문성 희석 방지 장치다.**
메인 계정은 쌍꺼풀, @days_harada_face는 전안면, @days_harada_kuma는 눈밑. 이 구조 덕분에 "이 의사는 쌍꺼풀 전문"이라는 포지션이 흔들리지 않는다. 단, 유성선병원은 5대 진료축을 모두 커버해야 하므로 초기에는 단일 계정으로 운영하되, 콘텐츠 비율 관리로 전문성을 유지한다.

### 1.2 대전 경쟁 지형에서 발견한 공백 3가지

**첫째, 안전 인프라 콘텐츠는 완전 공백이다.**
닥터스미가 바이오에 "마취통증의학과 전문의 상주"를 한 줄 적었을 뿐, 수술실 환경, 응급 대응 체계, 마취 모니터링 과정을 콘텐츠로 풀어내는 경쟁자는 단 하나도 없다. 종합병원 성형외과라는 유성선병원의 정체성을 SNS에서 가장 강력하게 차별화할 수 있는 영역이다.

**둘째, 치료/재건 콘텐츠는 인스타그램에서 부재한다.**
오체안 대전점이 유튜브에서 양성종양/피지낭종 콘텐츠를 다루지만 인스타그램에는 없다. 외상 봉합, 화상, 종양 제거를 다루는 인스타그램 계정이 대전에 전무하다. "미용만 하는 성형외과"라는 인식을 깨는 콘텐츠로 차별적 유입 경로를 확보할 수 있다.

**셋째, 유성구는 SNS 진공 상태다.**
올웨이즈윤대영이 유성구 유일 성형외과 개원의지만 SNS 수치조차 확인이 안 되는 수준이다. 둔산동에 밀집한 경쟁사들과 달리 유성구 상권에서 인스타그램 검색 시 사실상 경쟁자가 없다.

### 1.3 두 분석을 교차했을 때 도출되는 유성선만의 기회

@days_harada 모델은 "한 가지 시술의 절대 전문가"로 포지셔닝한다. 대전 경쟁사들도 모두 개원의 클리닉으로 미용 시술만 다룬다. 여기서 유성선병원의 구조적 차이가 기회로 전환된다.

```
@days_harada 모델      = 깊이(단일 시술 전문성)
대전 경쟁사 모델       = 넓이(다양한 미용 시술)
유성선병원 모델        = 깊이 + 안전 + 치료재건
```

종합병원 소속이라는 점은 개원의 클리닉 대비 "안전"이라는 감정적 가치를 고유하게 점유할 수 있다. 동시에 치료/재건 콘텐츠는 미용 목적이 아닌 환자까지 유입시키는 제2의 입구다. 이 두 축은 뉴진성형외과가 아무리 릴스를 잘 만들어도 따라올 수 없는 구조적 해자(moat)다.

## 2. SNS 포지셔닝 전략

### 2.1 경쟁 포지셔닝 맵

```
                        안전·의료 시스템 강조
                              ▲
                              │
                         유성선병원
                         (목표 포지션)
                              │
         닥터스미 ─────────────┼─────────────── 뉴진성형외과
         (안전 언급,           │                (스토리텔링,
          콘텐츠 미심화)       │                 높은 참여율)
                              │
              희소 ────────────┼──── 비포애프
              (학술 권위,      │     (B&A 양산,
               소규모)         │      낮은 참여율)
                              │
                              ▼
                     미용 결과물 중심
```

**핵심 해석:**
- 가로축(왼쪽: 안전/신뢰 → 오른쪽: 결과/스토리텔링)에서 뉴진성형외과가 우측 끝을 점유
- 세로축(위: 의료 시스템 → 아래: 미용 결과물)에서 상단은 완전 공백
- 유성선병원은 좌상단(안전 + 의료 시스템)을 독점하면서 콘텐츠 품질로 우측까지 확장

### 2.2 핵심 차별화 메시지

**1차 메시지 (브랜드 코어):**
> "대학병원의 안전함에 섬세함을 더하다"

**2차 메시지 (SNS 전용 변형):**
> "수술실 뒤에 종합병원이 있습니다"

**3차 메시지 (치료재건 전용):**
> "일상의 상처부터 섬세한 아름다움까지"

**희소성형외과 "섬세한 계획"과의 분리 전략:**
- 희소: "섬세한 계획" = 시술 계획의 정교함 (의사 역량 강조)
- 유성선: "섬세함을 더하다" = 종합병원 안전 인프라 위에 더해지는 미적 감각 (시스템 + 역량)
- SNS에서 "섬세함"을 단독으로 쓰지 않고, 반드시 "대학병원의 안전함"과 결합하여 사용

### 2.3 계정 정체성 정의

**계정명:** `@ysmc_plastic`

| 항목 | 설계안 |
|------|--------|
| **프로필 사진** | 신정환 과장 프로필 사진 (진료복 착용, 밝은 배경) |
| **이름 필드** | 유성선병원 성형외과 \| 신정환 과장 |
| **사용자 이름** | @ysmc_plastic |
| **카테고리** | 병원 (Hospital) |

**바이오 설계안 (150자 이내):**

```
대전 유성선병원 성형외과
대학병원의 안전함에 섬세함을 더하다
신정환 과장 | 성형외과 전문의
가톨릭중앙의료원 출신 | 보건복지부 장관 표창

## 3. 콘텐츠 전략

### 3.1 콘텐츠 5C 프레임워크

대전 경쟁 지형의 공백과 @days_harada의 성공 요인을 교차 반영한 5개 콘텐츠 카테고리.

| 카테고리 | 비율 | 정의 | 대전 공백 연동 |
|----------|------|------|---------------|
| **Clinical** | 30% | 시술 정보, 교육형 콘텐츠, 수술 과정 설명 | 페이스가 교육형을 시도하나 팔로워 전환 실패 -- 영상 품질로 차별화 |
| **Credibility** | 25% | 안전 시스템, 의료진 경력, 종합병원 인프라 | **완전 공백 -- 최우선 선점 영역** |
| **Case** | 20% | B/A 결과, 환자 경과 (심의 통과 콘텐츠) | 뉴진/비포애프가 활발하나 "안전한 환경에서의 결과"는 없음 |
| **Community** | 15% | 환자 Q&A, 댓글 소통, 지역 이벤트 | 대전 경쟁사 전반적으로 소통형 콘텐츠 부재 |
| **Culture** | 10% | 병원 일상, 의료진 인간적 면모, 팀 소개 | 닥터스미 "두쫀쿠" 릴스가 유일한 시도 |

### 3.2 게시물 유형별 비율

| 유형 | 비율 | 역할 | 주간 빈도 |
|------|------|------|-----------|
| **Reel (숏폼 영상)** | 40% | 바이럴 트리거, 알고리즘 도달 극대화 | 주 2회 |
| **Carousel (슬라이드)** | 30% | 교육형 정보 전달, 저장(Save) 유도 | 주 1~2회 |
| **Single Post (이미지)** | 15% | B/A, 의료진 소개, 시설 사진 | 주 1회 |
| **Story** | 15% | 일상 소통, 실시간 업데이트, 투표/Q&A | 매일 1~2개 |

**@days_harada와의 차이점:**
- harada는 Post 83% / Reel 17%이지만, 한국 인스타그램 알고리즘은 Reel 우선 노출이 더 강함
- 뉴진성형외과의 22,500명 팔로워 달성도 릴스 중심 전략의 결과
- 따라서 유성선병원은 Reel 비중을 40%로 설정 (harada의 2.4배)

### 3.3 게시 빈도 전략

| 단계 | 기간 | 빈도 | 근거 |
|------|------|------|------|
| Phase 1 (론칭기) | 1~4주 | 매일 1개 (주 7개) | @days_harada의 일 1회 게시 전략 적용, 알고리즘 학습 기간 |
| Phase 2 (성장기) | 5~8주 | 주 5~6개 | 뉴진성형외과(주 2~4회) 대비 우위 유지 |
| Phase 3 (안정기) | 9주~ | 주 4~5개 | 콘텐츠 품질 유지와 지속 가능성 균형 |

Story는 모든 단계에서 매일 1~2개 유지.

### 3.4 뉴진성형외과와의 차별화 전략

뉴진성형외과는 대전 SNS 성형외과 시장의 유일한 강적이다. 정면 경쟁이 아닌 비대칭 전략으로 접근한다.

| 뉴진의 강점 | 유성선의 대응 |
|-------------|--------------|
| 스토리텔링 릴스 (환자 여정 서사) | **따라간다** -- 릴스 품질은 필수 역량, 영상 편집 수준을 뉴진과 동등하게 맞춤 |
| 권유진 원장 퍼스널 브랜딩 | **따라간다** -- 신정환 과장 브랜딩, 단 "종합병원 과장"이라는 독자적 포지션 |
| 22,500명 팔로워 | **우회한다** -- 팔로워 숫자 경쟁 대신 참여율과 전환율(예약)에 집중 |
| 미용성형 100% 콘텐츠 | **차별화한다** -- 치료재건 콘텐츠로 뉴진이 들어올 수 없는 영역 선점 |
| 둔산동(서구) 입지 | **차별화한다** -- 유성구 유일 성형외과 포지션 강화 |
| YouTube 쇼츠 교차배포 | **따라간다** -- 릴스/쇼츠 동시 배포 전략 동일하게 적용 |

**뉴진이 절대 따라올 수 없는 3가지:**
1. "수술 중 응급상황 시 종합병원 전체가 백업한다"는 메시지
2. 외상/화상/종양 치료 콘텐츠 (개원의 클리닉에서는 불가능)
3. 보건복지부 장관 표창, 대한공중보건의사협의회 회장 이력 (공공 의료 신뢰)

[ZONE 4 -- 주의사항] ★ 의료법 준수

[ZONE 5 -- CTA + 클리닉 푸터]

[ZONE 6 -- 해시태그]

#### 템플릿 B: 신뢰형 (Credibility 카테고리용)

```
[ZONE 1 -- 후크]
{안전/시스템 관련 질문 또는 상황 제시}
"수술 중에 문제가 생기면 어떻게 하나요?"

[ZONE 2 -- 답변 + 시스템 설명]

## 7. 의료광고 컴플라이언스 체크리스트

### 7.1 B/A(Before/After) 심의 프로세스

한국에서 B/A 콘텐츠를 인스타그램에 게시하려면 **의료광고 사전심의**를 반드시 거쳐야 한다.

**심의 기관:** 대한의사협회 의료광고심의위원회

**심의 절차:**

| 단계 | 내용 | 소요 기간 |
|------|------|-----------|
| 1단계 | 게시 예정 콘텐츠(이미지+캡션) 심의 신청서 작성 | 1일 |
| 2단계 | 환자 동의서 첨부 (촬영 동의 + 광고 활용 동의) | 사전 확보 |
| 3단계 | 심의위원회 검토 | 7~14일 |
| 4단계 | 승인/수정요청/반려 통보 | - |
| 5단계 | 수정 후 재심의 (필요 시) | 추가 7일 |
| 6단계 | 승인 후 게시 (심의번호 표기) | - |

**B/A 게시물 필수 기재 사항:**
- 심의번호
- "개인에 따라 결과가 다를 수 있으며, 부작용이 발생할 수 있습니다" 문구
- 수술/시술 후 주의사항
- 촬영 시점 (수술 후 경과 기간)

**실무 팁:**
- Phase 1(1~4주)에는 B/A 없이 교육형 + 안전 콘텐츠로 운영
- Phase 0 기간에 첫 B/A 심의를 미리 신청하여 Phase 2에 게시 가능하도록 준비
- 한 번에 5~10건을 묶어 심의 신청하면 효율적

### 7.3 게시 전 체크리스트

모든 게시물은 발행 전 아래 항목을 확인한다. 담당자와 감수자 2인이 각각 체크한다.

**[필수 확인 -- 법적 사항]**

- [ ] "최고", "완벽", "100%" 등 최상급/보장 표현이 없는가
- [ ] "원장"이 아닌 "과장" 또는 "전문의"로 호칭했는가
- [ ] 가격, 할인, 이벤트 등 경제적 유인 표현이 없는가

- [ ] B/A 게시물에 심의번호가 표기되어 있는가
- [ ] "개인에 따라 결과가 다를 수 있으며, 부작용이 발생할 수 있습니다" 문구가 있는가

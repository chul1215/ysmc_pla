## 1. 분석 개요

## 2. @days_harada 계정 심층 분석

### 2.1 계정 포지셔닝 전략

@days_harada의 핵심 포지셔닝은 **"쌍꺼풀 수술의 절대 전문가"**로 요약된다.

**포지셔닝 구조 분석:**

```
[1차 정체성] 쌍꺼풀 매몰법 전문의
  └─ [2차 확장] 눈 전체 수술 (눈매교정, 앞트임 등)
      └─ [3차 확장] 전안면 성형 (서브계정으로 분리)
```

이 전략의 핵심 원칙은 다음과 같다.

1. **단일 시술 집중**: 프로필명 자체가 "쌍꺼풀 수술/매몰법 하라다 히로미츠"로, 검색 최적화와 전문성 인지를 동시에 달성한다.
2. **넓이보다 깊이**: 메인 계정은 쌍꺼풀에 집중하고, 안면 전체/눈밑은 서브계정으로 분리하여 전문성 희석을 방지한다.
3. **인증 배지 활용**: 파란 뱃지(공식 인증)로 신뢰도를 시각적으로 확보한다.
4. **의사 개인 = 브랜드**: 클리닉명이 아닌 의사 개인 이름을 계정의 중심에 배치하여, 의사가 이동하더라도 브랜드 자산이 유지되는 구조다.

**유성선 적용 시사점:** 종합병원 소속이라는 특성상 개인 브랜딩과 병원 브랜딩의 균형이 필요하다. "신정환 과장"이라는 전문가 아이덴티티와 "유성선병원"이라는 기관 신뢰도를 결합하는 이중 포지셔닝이 유효하다.

### 2.2 콘텐츠 아키텍처

#### 유형별 비율 분석

최근 12개 게시물 기준:

| 유형 | 수량 | 비율 | 평균 좋아요 | 평균 댓글 |
|------|------|------|------------|----------|
| Post (이미지) | 10개 | 83% | 57.8 | 2.3 |
| Reel (영상) | 2개 | 17% | 186.0 | 5.5 |

**핵심 발견사항:**

- **Reel이 Post 대비 좋아요 3.2배, 댓글 2.4배 높은 성과**를 보인다.
- 역대 최고 성과는 Reel (9,600 좋아요)로, Post 최고 대비 약 90배 차이가 난다.
- 그럼에도 Post 비율이 83%인 이유는 **Before/After 이미지의 정보 밀도**가 높고, 제작 허들이 낮기 때문으로 분석된다.
- Reel은 주 1~2회로 "바이럴 트리거" 역할, Post는 매일 업로드로 "신뢰 축적" 역할로 분업한다.

#### 게시 빈도 분석

- **평균 게시 빈도**: 일 1회 (월 25~30개)
- **동시 발행**: 같은 날 Reel + Post를 동시 업로드하는 경우 존재
- **공백 없음**: 12개 게시물이 15일 이내에 분포 -- 거의 매일 게시

**빈도 전략 해석:** 성형외과 인스타그램에서 "매일 게시"는 단순한 노출 극대화가 아니라, **"이 의사는 매일 수술을 한다 = 경험이 풍부하다"**는 잠재적 메시지를 전달한다.

#### 이미지 포맷

| 유형 | 비율 | 용도 |
|------|------|------|
| Reel | 9:16 (720x1280) | 수술 과정 타임랩스, 결과 강조 영상 |
| Post | 4:5 (720x900) | Before/After 비교 이미지 |

콘텐츠의 100%가 시술 결과물(Before/After)이다. 병원 시설, 일상, 교육 콘텐츠가 전무하다는 점이 특징적이며, 이는 **"결과로 말한다"**는 메시지를 극대화하는 전략이다.

### 2.3 캡션 전략

@days_harada의 캡션은 고도로 시스템화된 템플릿 구조를 따른다. 이는 "매일 게시"를 가능하게 하는 운영 효율성의 핵심이다.

#### 템플릿 해체 분석

```
[ZONE 1: 후크 — 결과 요약]
"○○ 시술로 △△해졌습니다"
→ 시술명 + 결과를 한 문장으로. 검색 노출 + 스크롤 정지 역할.

[ZONE 2: 브랜드 철학 블록]
"쌍꺼풀 시술은 디자인이 전부입니다"
"상담에서 0.1mm 단위로 디자인 결정"
"의사의 압도적인 경험과 감각으로 결과가 달라집니다"
→ 고정 문구. 반복 노출을 통해 브랜드 인지 각인.

[ZONE 3: 차별화 포인트 (불릿)]
#하라다원장쌍꺼풀술 → 4가지 차별화 포인트
→ 브랜드 해시태그를 앵커로 차별화 메시지 전달.

[ZONE 4: 시술 정보 블록]
■시술 내용 / ■가격 / ■예상 부작용 및 리스크
→ 일본 의료광고 가이드라인 준수. 시술 내용, 가격, 리스크를 반드시 명시.

[ZONE 5: 클리닉 정보 푸터]
전화번호, 주소, 역 도보 시간
→ 전환(상담 예약)을 위한 고정 정보.

[ZONE 6: 해시태그]
4~5개 집중형
→ 과도한 해시태그 남발을 지양하고 핵심 키워드에 집중.
```

**캡션 전략의 핵심 원칙:**

1. **반복이 브랜딩이다**: ZONE 2의 브랜드 철학 문구를 모든 게시물에 동일하게 삽입. 팔로워가 여러 게시물을 볼수록 "0.1mm 단위 디자인"이라는 메시지가 각인된다.
2. **템플릿 = 운영 효율성**: 매일 게시에도 캡션 작성에 소요되는 시간이 최소화된다. 변경되는 부분은 ZONE 1(시술 결과)과 ZONE 4(시술 상세) 뿐이다.
3. **법적 준수가 신뢰가 된다**: 가격과 리스크를 명시하는 것이 법적 의무이자 동시에 "투명한 의사"라는 신뢰 신호로 작용한다.

### 2.4 해시태그 전략

12개 게시물의 해시태그를 전수 분석한 결과, 3단계 계층 구조가 확인된다.

#### 해시태그 계층 구조

| 계층 | 해시태그 | 출현 빈도 | 역할 |
|------|---------|-----------|------|
| Tier 1: 브랜드 | #하라다원장쌍꺼풀술 | 11/12 (92%) | 자체 브랜드 태그. 검색 시 본인 게시물만 노출 |
| Tier 2: 시술 카테고리 | #쌍꺼풀수술, #성형, #매몰법, #쌍꺼풀매몰 | 10~12/12 | 시술 검색 트래픽 유입 |
| Tier 3: 시술 상세 | #전안면성형, #앞트임, #눈전체성형 | 1~3/12 | 특정 시술 관심 환자 타겟팅 |

**해시태그 전략의 핵심 원칙:**

1. **브랜드 해시태그 필수**: #하라다원장쌍꺼풀술은 경쟁자가 사용할 수 없는 독점 키워드다. 환자가 이 태그를 검색하면 하라다의 전체 포트폴리오를 한눈에 볼 수 있다.
2. **소수 정예 (4~5개)**: 인스타그램 알고리즘이 과도한 해시태그(20~30개)를 스팸으로 인식하는 경향이 있다. 핵심 키워드에 집중하는 것이 노출 효율이 높다.
3. **고정 + 변동 조합**: Tier 1~2는 모든 게시물에 고정, Tier 3만 시술 내용에 따라 변경한다.

**설계 원칙:**

- 시술 카테고리별 하이라이트가 2개(안검하수, 매몰법)로, 메인 계정의 핵심 시술에만 집중한다.
- 영업 달력과 예약 관련 하이라이트는 DM 문의를 줄이고 전환 동선을 단축하는 실용적 역할을 한다.

### 2.6 댓글 전략

@days_harada의 가장 독특한 전술은 **"댓글란 유도"** 전략이다.

#### 전술 구조

```
[게시물 캡션 내]
"시술 상세는 댓글란에서→"

[댓글란]
의사 본인이 시술 파트별로 분리 작성:
  댓글 1: 눈 수술 상세
  댓글 2: 윤곽 수술 상세
  댓글 3: 코 수술 상세
  → 각 댓글이 좋아요 7~9개 획득
```

**이 전술의 효과 분석:**

1. **알고리즘 우대**: 인스타그램 알고리즘은 댓글 수가 많은 게시물을 우선 노출한다. 의사 본인이 3~5개 댓글을 작성하는 것만으로 "댓글이 활발한 게시물"로 인식된다.
2. **정보 구조화**: 캡션에 모든 시술 정보를 넣으면 길이가 과도해진다. 댓글로 분리하면 관심 있는 시술만 선택적으로 읽을 수 있다.
3. **체류 시간 증가**: 댓글란을 열어보게 함으로써 게시물 체류 시간이 늘어나고, 이는 다시 알고리즘에 긍정 신호를 보낸다.
4. **의사-환자 댓글이 혼재**: 본인 댓글 사이에 환자 문의가 자연스럽게 섞이면서, 댓글란 전체가 "활발한 소통의 장"으로 보인다.

### 2.7 서브계정 전략

@days_harada는 메인 + 서브 2개, 총 3개 계정을 운영한다.

| 계정 | 콘텐츠 범위 | 역할 |
|------|------------|------|
| @days_harada (메인) | 쌍꺼풀 매몰법 중심 | 트래픽 허브, 브랜드 인지 |
| @days_harada_face | 전안면 성형 (코, 윤곽, 리프팅) | 영역 확장, 크로스셀링 |

**서브계정 전략의 핵심:**

1. **전문성 희석 방지**: 한 계정에서 쌍꺼풀, 코, 윤곽, 눈밑을 모두 다루면 "무엇이든 하는 의사"로 인식될 수 있다. 계정 분리로 각각의 전문성을 유지한다.
2. **계정명 = 시술명**: @days_harada_kuma에서 "kuma(쿠마)"는 일본어로 눈밑 다크서클을 의미. 시술을 검색하는 환자가 계정명에서 바로 전문성을 인지한다.
3. **크로스 프로모션**: 메인 계정 바이오에서 서브계정을 명시하고, 서브계정에서 메인으로 유도하는 순환 구조를 만든다.

### 2.8 수치 기반 성과 분석

#### Reel vs Post 성과 비교

| 지표 | Post (이미지) | Reel (영상) | Reel 우위 |

| 평균 좋아요 (최근 12개) | 57.8 | 186.0 | 3.2배 |
| 평균 댓글 (최근 12개) | 2.3 | 5.5 | 2.4배 |
| 역대 최고 좋아요 | ~103 | 9,600 | ~93배 |
| 최근 높은 Reel | - | 468 (2026-02-28) | - |

#### 바이럴 패턴

- **일상적 성과**: Post 35~68 좋아요 / Reel 123~249 좋아요
- **중간 바이럴**: Post 103 좋아요 / Reel 468 좋아요 (상위 10% 추정)
- **대형 바이럴**: Reel 9,600 좋아요 (76주 전, 확률적으로 연 1~2회 발생)

**바이럴 패턴 해석:**

Reel의 바이럴 가능성은 Post의 수십 배에 달하지만, 발생 확률이 낮다(741개 게시물 중 대형 바이럴은 극소수). 따라서 최적 전략은 **Post로 일일 기반을 유지하면서, Reel을 주 1~2회 "바이럴 복권"으로 발행하는 것**이다. 매일 Reel만 제작하는 것은 리소스 대비 효율이 떨어진다.

#### 팔로워 대비 인게이지먼트율

```
평균 좋아요 / 팔로워 = 57.8 / 77,000 = 0.075%
(Reel 포함 시) = 79.2 / 77,000 = 0.10%
```

이는 성형외과 계정 평균(0.5~1.5%)보다 낮은 수치다. 이유는 팔로워 77,000명 중 상당수가 비활성 계정이거나 시술 완료 후 관심이 줄어든 과거 환자로 추정된다. 이는 성형외과 계정의 구조적 특성이며, **순수 인게이지먼트율보다 상담 전환율이 더 중요한 KPI**라는 점을 시사한다.

### 3.4 대전 지역 특수성

대전 성형외과 시장은 인스타그램 마케팅의 **블루오션**이다.

- 개원의 9곳 중 인스타그램을 체계적으로 운영하는 곳이 없다.
- 환자 유입의 70% 이상이 네이버 경유이며, SNS는 미개척 영역이다.
- 이는 역설적으로 **선점 효과가 극대화되는 환경**이다.
- 경쟁자의 SNS 부재로, 적은 팔로워로도 지역 내 인지도 확보가 가능하다.

#### 의료법 제56조 주요 금지사항 체크리스트

- [ ] 허위/과대 광고 금지: "최고", "유일", "100%" 등 절대적 표현 사용하지 않음
- [ ] 치료 효과 보장 금지: "반드시 만족", "실패 없는" 등 결과 보장 표현 사용하지 않음
- [ ] 다른 의료기관 비방 금지: 경쟁 병원/의원과의 직접 비교 광고 금지
- [ ] 경제적 유인 금지: 할인, 무료 시술, 리베이트 등 경제적 유인 제공 광고 금지
- [ ] 환자 유인 금지: "지금 예약하면 특별 혜택" 등 긴급성 조성 표현 금지
- [ ] 인증되지 않은 경력 금지: 공인된 전문의 자격, 학력, 경력만 광고 가능

#### 심의 프로세스 권장 절차

```
1. 콘텐츠 제작 (이미지 + 캡션)
   ↓
2. 내부 검토 (마케팅팀 + 의료진 + 법무)
   ↓
3. 대한의사협회 의료광고심의위원회 심의 신청
   (B/A 포함 시 필수, 교육형 콘텐츠는 심의 불요 가능)
   ↓
4. 심의 결과 수령 (통상 7~14일)
   ↓
5. 심의 통과 → 게시 (심의 번호 표기)
   심의 거부 → 수정 후 재신청
```

**실무 팁**: B/A 콘텐츠는 최소 게시 2~3주 전에 심의 신청해야 한다. 월간 콘텐츠 계획 시 심의 소요 기간을 역산하여 스케줄링할 것.

### 7.3 종합병원 소속 특수 주의사항

1. **병원 전체 브랜드와의 정합성**: 유성선병원의 공식 SNS 채널이 별도로 존재할 수 있다. 성형외과 계정의 톤앤매너가 병원 전체 브랜드와 충돌하지 않도록 사전 조율이 필요하다.

2. **원내 커뮤니케이션**: 타 진료과와의 협진 콘텐츠(예: 피부과 연계 시술, 마취과 협력) 게시 시 해당 과의 사전 동의를 받아야 한다.

3. **인사 관련**: 담당의 이동/퇴직 시 계정 자산의 귀속 문제. 계정 소유권은 병원에 귀속되도록 초기에 명확히 해야 한다.

4. **"과장" 호칭 일관성**: 모든 게시물에서 "신정환 과장"으로 통일. "원장", "대표원장" 등의 호칭은 종합병원 진료과 형태에 맞지 않으므로 사용하지 않는다.

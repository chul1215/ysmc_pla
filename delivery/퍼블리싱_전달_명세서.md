## 3. 코드 아키텍처

### 핵심 특징: 파일 완전 자급자족

- **공유 CSS/JS 파일이 없음** — 모든 스타일과 스크립트는 각 HTML 파일 내 `<style>`, `<script>` 블록에 인라인
- 공통 요소(헤더, 푸터, 색상 변수 등)를 수정하려면 **해당되는 모든 HTML 파일을 각각 수정**해야 함

### 헤더 구조 (전 페이지 공통)

단일 토바 1줄 구성 (높이: PC 48px / 모바일 44px):

```
[선메디컬센터 유성선병원 성형외과]          병원소개 | 미용성형센터 | 외상·재건센터  [≡]
```

- 좌측: 로고 텍스트 (`.logo-text`, index.html 링크)
- 우측: 탭 네비게이션 (`.topbar-nav` > `.topbar-tab` × 3)
- 모바일: 탭 숨김, 햄버거 메뉴 → 풀스크린 오버레이
- 현재 페이지는 해당 탭에 `.active` 클래스

### 모바일 내비게이션

- 햄버거 클릭 시 `.mobile-nav-overlay` 풀스크린 오버레이 표시
- 미용성형/치료재건 센터 전환 탭 + 시술별 링크 그리드 + CTA 버튼

│   ├── safety-medical/

## 9. admin.html 상세 (운영 관리 페이지)

공개 사이트와 분리된 내부 운영 관리 페이지. 공개 페이지에서 링크되지 않음.

| 항목 | 내용 |
|------|------|
| 타이틀 | 유성선병원 성형외과 MASTER PAGE |
| 스택 | Tailwind CSS (CDN), Google Fonts (Noto Sans KR) — 인터넷 필수 |
| 테마 | `<html class="dark">` 고정 (다크 모드만) |
| 인증 | `sessionStorage('ysmc_admin')` — JS 내 `ADMIN_PW` 상수 (정적 사이트 한계) |
| GNB | 없음 (사이드바 메뉴 방식) |

### 관리 메뉴 4개
1. **팝업 관리** — index.html 팝업 표시용 (`localStorage: ysmc_popup`)
2. **수술후기 관리** — 후기 목록 (`localStorage: ysmc_reviews`)
3. **공지사항 관리** — 공지 목록 (`localStorage: ysmc_notices`)
4. **온라인 상담** — 상담 접수 관리 (`localStorage: ysmc_consultations`), 미확인 뱃지 표시

### 이미지 업로드 방식

팝업 관리 및 수술후기 등록 시 이미지는 **파일 직접 업로드** 방식을 사용합니다.

| 항목 | 내용 |
|------|------|
| 입력 방식 | `<input type="file" accept="image/*">` 파일 선택 |
| 저장 방식 | `FileReader.readAsDataURL()`로 Base64 변환 → `localStorage`에 저장 |
| 지원 포맷 | 브라우저가 허용하는 모든 이미지 형식 (JPG, PNG, WebP 등) |
| 미리보기 | 파일 선택 즉시 썸네일 표시, × 버튼으로 삭제 |
| 저장 키 | `ysmc_popup.imageUrl`, `ysmc_reviews[].imageUrl` (Data URL 문자열) |

> **주의**: Base64 이미지는 원본 파일 크기의 약 1.37배로 저장됩니다. `localStorage` 용량 한도(도메인당 약 5MB)를 고려해 고해상도 원본보다는 리사이즈 후 업로드를 권장합니다.

> localStorage를 통해 공개 페이지와 데이터를 공유하는 구조이나, 현재 연동은 미구현(TODO) 상태임.

## 1. 바이오 3가지 버전

> 인스타그램 바이오 150자 제한. 줄바꿈이 그대로 표시됩니다.
> 3가지 중 하나를 선택하거나, 상황에 따라 교체 운영 가능.

---

### [버전 A — 정석형]
전문성·신뢰 중심, 처음 방문자에게 정보 전달 우선.

```
대전 유성선병원 성형외과
대학병원의 안전함에 섬세함을 더하다

신정환 과장 | 성형외과 전문의
가톨릭중앙의료원 출신 | 보건복지부 장관 표창
👁 눈 · 리프팅 · 쁘띠 · 외상 · 재건
```

---

### [버전 B — 감성형]
브랜드 철학을 먼저, 정보는 아래로.

```
상처도, 아름다움도
섬세하게 다루는 성형외과

신정환 과장 · 성형외과 전문의
대전 유성구 유성선병원 검진 3층
눈 · 리프팅 · 쁘띠 · 외상 · 재건
```

---

### [버전 C — 간결형]
모바일 미리보기 2줄 내 핵심 메시지 완결.

```
유성선병원 성형외과 | 신정환 과장
종합병원의 안전 + 성형외과의 섬세함

대전 유성구 · 눈 리프팅 쁘띠 외상 재건
보건복지부 장관 표창 | 가톨릭중앙의료원 출신
```

## 3. 고정 1번 댓글 CTA

> 모든 게시물 업로드 직후 **본인 계정으로 첫 번째 댓글**에 고정.

### [기본형] — 교육형·신뢰형 게시물에 사용
```
상담 예약은 프로필 링크에서 가능합니다 🔗
궁금한 점은 댓글로 남겨주세요.
신정환 과장이 직접 확인하고 답변드립니다.
```

### [소통형] — 커뮤니티·일상 게시물에 사용
```
댓글로 편하게 질문 남겨주세요 😊
예약·상담 문의는 프로필 링크에서 가능합니다.
```

### [치료재건 전용] — 외상·종양·화상 콘텐츠에 사용
```
증상이 걱정되신다면 먼저 상담 주세요.
프로필 링크 또는 카카오톡으로 문의 가능합니다.
빠른 확인이 필요한 경우 전화 주시면 안내드립니다 📞
```

## 4. DM 응답 템플릿 4종

> `[ ]` 안은 상황에 맞게 교체.

---

### [템플릿 1] 첫 문의 — 시술 상담 요청
```
안녕하세요, 유성선병원 성형외과입니다 😊
[시술명] 관련 문의 주셨군요.

[시술명]은 개인의 눈 모양·피부 상태·생활 패턴에 따라
방법과 회복 기간이 달라질 수 있어,
직접 뵙고 확인해 드리는 것이 가장 정확합니다.

내원 상담을 원하시면 아래로 예약해 주세요 🔗
· 예약 링크: 프로필 링크 내 [예약하기]
· 전화: 042-000-0000
· 카카오톡: @유성선성형외과

간단한 궁금증은 이곳에서 먼저 안내해 드릴게요.
편하게 질문 주세요!
```

부담 없는 상담으로 먼저 확인해 보세요 🙏

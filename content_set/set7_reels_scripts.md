# Set 7 — 릴스 대본 (Week 1~4, 8편)

> 실제 촬영 시 과장님이 읽을 대본 + 자막 구성안.
> `[Hook]` `[본문]` `[CTA]` 3파트 구조로 통일.
> 자막 텍스트는 말하는 순서와 동일하게 배치.

---

## Reel 1 — Week 1 (월)
**제목: "대전 유성에 성형외과가 생겼습니다"**
포맷: 시네마틱 투어 / 15~30초 / 말하지 않아도 되는 자막 중심

```
[촬영 순서 & 자막]

(병원 외관 or 간판 샷)
자막: "대전 유성구에 성형외과가 생겼습니다."

(로비 → 복도 이동)
자막: "그냥 생긴 게 아닙니다."

(수술실 전경)
자막: "종합병원 안에,"

(신정환 과장 정면 인사)
과장님 멘트: "안녕하세요, 신정환 과장입니다."
자막: "전문의가 직접."

(병원 정보 자막 페이드인)
자막: "종합병원의 안전함에 섬세함을 더하다"
자막: "유성선병원 검진 3층 성형외과"
자막: "상담 예약 → 프로필 링크"
```

**촬영 팁:** BGM은 차분하고 고급스러운 분위기. 과편집 없이 깔끔하게.

## Reel 3 — Week 2 (화)
**제목: "눈매교정이 필요한 눈 vs 필요 없는 눈"**
포맷: 신정환 과장 정면 + 그래픽 병행 / 30초

```
[Hook, 0~3초]
과장님 멘트:
"쌍꺼풀 수술만 하면 되는 눈이 있고,
 눈매교정이 필요한 눈이 있습니다."

자막 동시 표시:
"쌍꺼풀 수술만 하면 되는 눈 / 눈매교정이 필요한 눈"

─────────────────────

[본문, 4~25초]
(그래픽 전환)
과장님 멘트:
"졸려 보이는 눈의 원인은 두 가지입니다.
 첫 번째, 쌍꺼풀이 없어서.
 두 번째, 눈꺼풀 근육 힘이 약한 안검하수."

자막:
"① 쌍꺼풀이 없어서 → 쌍꺼풀 수술"
"② 눈꺼풀 근육이 약해서 → 눈매교정 필요"

과장님 멘트:
"눈을 크게 뜰 때 이마에 힘이 들어가신다면
 안검하수를 의심해볼 수 있습니다.
 원인을 정확히 파악해야 원하는 결과를 얻을 수 있습니다."

─────────────────────

[CTA, 26~30초]
자막: "궁금하신 분 → 프로필 링크에서 상담 예약"
과장님 멘트: (선택) "편하게 상담 주세요."
```

## Reel 4 — Week 2 (금)
**제목: "눈밑 지방재배치, 이런 분에게 추천합니다"**
포맷: 신정환 과장 토킹헤드 / 30초

```
[Hook, 0~3초]
과장님 멘트:
"눈밑이 볼록하고 다크서클도 심하다면,
 단순 지방 제거보다 재배치가 맞을 수 있습니다."

─────────────────────

[본문, 4~25초]
과장님 멘트:
"눈밑 지방재배치가 맞는 경우를 말씀드릴게요."

자막:
"① 눈밑이 볼록하게 튀어나온 경우"
"→ 지방을 꺼진 부위로 이동"

자막:
"② 눈밑 꺼짐·다크서클이 함께 있는 경우"
"→ 볼록한 곳 줄이고 꺼진 곳 채움"

자막:
"③ 피부 탄력이 어느 정도 남아 있는 경우"
"→ 피부 절개 없이 진행 가능"

과장님 멘트:
"단순 제거가 맞는 경우도 있으니
 직접 확인이 먼저입니다."

─────────────────────

[CTA, 26~30초]
자막: "프로필 링크에서 상담 예약해 주세요."
```

## Reel 5 — Week 3 (월)
**제목: "성형수술 중 응급상황, 종합병원은 이렇게 대응합니다"**
포맷: 그래픽 인포그래픽 + 과장님 오프닝·마무리 / 30초

```
[Hook, 0~3초]
과장님 멘트:
"수술 중에 문제가 생기면 어떻게 하나요?
 가장 많이 받는 질문입니다."

─────────────────────

[본문, 4~25초]
(그래픽 전환)
자막:
"유성선병원의 대응 체계"

자막 순서:
"① 이상 징후 → 마취통증의학과 즉시 협진"
"② 응급 처치 필요 → 응급의학과·내과 연결"
"③ 검사 필요 → CT·혈액검사 즉시 시행"
"④ 입원 필요 → 중환자실 즉시 이송"

과장님 멘트:
"개인 클리닉에서는 갖추기 어려운 구조입니다.
 이것이 종합병원 성형외과를 선택하는 이유입니다."

─────────────────────

[CTA, 26~30초]
자막: "유성선병원 검진 3층 성형외과"
자막: "프로필 링크에서 상담 예약"
```

## Reel 6 — Week 3 (금)
**제목: "신정환 과장이 말하는 안전한 수술의 조건"**
포맷: 신정환 과장 인터뷰 형식 / 45초

```
[Hook, 0~3초]
과장님 멘트:
"안전한 수술이 뭔지 물으신다면,
 저는 세 가지로 답합니다."

─────────────────────

[본문, 4~40초]
과장님 멘트:
"첫 번째, 수술 전 철저한 검사입니다."
자막: "수술 전 철저한 검사"
과장님 멘트:
"혈액검사, 심전도, 기저질환 확인.
 몸 상태를 모르면 수술을 시작하지 않습니다."

과장님 멘트:
"두 번째, 마취 관리입니다."
자막: "마취 관리"
과장님 멘트:
"마취는 수술만큼 중요합니다.
 마취통증의학과 전문의가 처음부터 끝까지 함께합니다."

과장님 멘트:
"세 번째, 사후 관리입니다."
자막: "사후 관리"
과장님 멘트:
"수술이 끝나도 회복 과정이 안전해야 합니다.
 이상 발생 시 바로 대응할 수 있어야 합니다."

과장님 멘트:
"이 세 가지가 갖춰진 곳에서 수술받으세요."

─────────────────────

[CTA, 41~45초]
자막: "유성선병원 검진 3층 성형외과"
자막: "프로필 링크에서 상담 예약"
```

## Reel 7 — Week 4 (월)
**제목: "얼굴에 상처가 났을 때, 성형외과에 가야 하는 이유"**
포맷: 그래픽 + 과장님 / 30초

```
[Hook, 0~3초]
자막: "얼굴에 상처가 났을 때, 어디로 가야 할지 모르셨던 분 계시죠?"

─────────────────────

[본문, 4~25초]
자막:
"성형외과 봉합이 다른 이유"

자막 순서:
"① 피부층을 세밀하게 맞춰 봉합합니다."
"② 흉터가 최소화되도록 봉합법을 선택합니다."
"③ 부위·깊이·방향에 따라 달리 처치합니다."

과장님 멘트:
"빠를수록 좋습니다.
 상처 후 6~8시간 이내가 원칙입니다."

자막:
"유성선병원은 종합병원 — 응급 후 즉시 성형외과 협진 가능"

─────────────────────

[CTA, 26~30초]
자막: "전화 042-000-0000"
자막: "또는 프로필 링크에서 바로 문의"
```

## Reel 8 — Week 4 (금)
**제목: "아이 얼굴에 상처가 났을 때 (소아 외상)"**
포맷: 신정환 과장 / 공감 톤 / 30초

```
[Hook, 0~3초]
과장님 멘트:
"아이 얼굴에 상처가 났을 때,
 부모님 마음이 얼마나 급하실지 압니다."

─────────────────────

[본문, 4~25초]
과장님 멘트:
"소아 외상에서 꼭 알아두실 것들이 있습니다."

자막 순서:
"첫째, 아이 피부는 어른보다 얇고 예민합니다."
"→ 더 세밀한 처치가 필요합니다."

"둘째, 협조가 어려운 아이일수록"
"→ 안정적인 환경이 처치 결과에 영향을 줍니다."

"셋째, 흉터 관리는 성장하면서 달라집니다."
"→ 나이에 맞는 장기 관리가 필요합니다."

과장님 멘트:
"서두르지 말고, 올바른 곳에서 처치받으세요."

─────────────────────

[CTA, 26~30초]
자막: "유성선병원 검진 3층 성형외과"
```

## 공통 릴스 제작 가이드

| 항목 | 기준 |
|------|------|
| 해상도 | 9:16 세로형 (1080×1920) |
| 길이 | 30초 (기본) / 45~60초 (교육·신뢰형) |
| 비주얼 톤 | 화이트·베이지·민트 계열 배경, 과한 편집 지양 |
| 과장님 복장 | 진료복 or 정장 (수술복은 수술실 촬영 시만) |
| 자막 폰트 | Pretendard 계열 / 흰색 or 어두운 배경에 흰색 |
| BGM | 차분하고 신뢰감 있는 분위기 / 가사 없는 음악 권장 |
| 마무리 | 반드시 병원명 + 위치 + CTA 자막으로 종료 |

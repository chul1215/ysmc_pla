### [스토리 Q&A 1] 눈성형 — 회복 기간

**수집된 질문:**
"쌍꺼풀 수술 후 며칠 만에 정상 생활이 되나요?"

**답변 스토리 문구:**
```
많이 물어봐 주신 질문이에요 😊

쌍꺼풀 수술 회복 타임라인

1~3일: 붓기 최고조, 멍 생길 수 있음
→ 집 안에서 회복 권장

3~7일: 붓기 줄어들기 시작, 실밥 제거
→ 일상 복귀 가능하지만 선글라스 착용 권장

2주: 일상생활 대부분 가능
→ 주변에서 눈치 채지 못하는 분들도 계세요

1~3개월: 최종 결과에 가까워지는 시기

개인 체질과 수술 방법에 따라 달라질 수 있어요.
정확한 일정은 상담에서 같이 계획 세워드릴게요 🙂
```

### [스토리 Q&A 2] 리프팅 — 가격 문의

**수집된 질문:**
"울쎄라랑 써마지 가격이 어떻게 되나요?"

**답변 스토리 문구:**
```
비용 문의 주신 분들이 많으셨어요 😊

비용은 시술 범위·횟수·부위에 따라 달라져서
정확한 금액은 상담 후 안내드리고 있어요.

가격만으로 결정하기보다
현재 피부 상태에 맞는 시술이 어떤 건지
먼저 확인하고 결정하시는 게 중요해요.

부담 없이 상담 먼저 받아보세요.
프로필 링크에서 예약 가능합니다 🔗
```

### [스토리 Q&A 3] 쁘띠 — 내성

"보톡스 오래 맞으면 진짜 내성 생기나요?"

**답변 스토리 문구:**
```
많이 궁금해하시는 내용이에요!

적정 간격을 지키면 내성 걱정은 크지 않아요.

하지만 너무 짧은 간격으로 반복하면
효과 지속 시간이 달라질 수 있어요.

보통 3~6개월 간격이 기본입니다.
현재 효과가 짧게 느껴지신다면 상담에서 확인해 드려요 😊

프로필 링크에서 예약 가능합니다.
```

### [스토리 Q&A 5] 종합병원 — 차이점

**수집된 질문:**
"종합병원 성형외과가 진짜로 더 안전한가요?"

**답변 스토리 문구:**
```
솔직하게 말씀드릴게요.

성형외과 전문의 실력은
어느 곳이나 수련을 마친 전문의라면 기본기가 있어요.

그럼 뭐가 다르냐면:

수술 중 예상치 못한 상황이 생겼을 때,
종합병원은 마취과·응급의학과·중환자실이
바로 연결됩니다.

개인 클리닉에서는 구조적으로 어려운 부분이에요.

"드물지만 생길 수 있는 상황에 대비"
이것이 종합병원을 선택하는 이유예요.
```

## 스토리 운영 가이드

| 항목 | 기준 |
|------|------|
| 게시 빈도 | 매일 1~2개 |
| 질문 수집 | 질문 스티커 → 다음 스토리 또는 피드 콘텐츠로 전환 |
| 투표 활용 | 주 1~2회 주제 투표 → 반응 많은 주제 우선 제작 |
| 답변 원칙 | 의학적 판단 필요 사항은 "직접 상담 필요" 안내로 전환 |
| CTA 연결 | 모든 Q&A 스토리 마지막에 예약 링크 또는 전화번호 삽입 |
| 하이라이트 저장 | 유익한 Q&A는 "Q&A" 하이라이트에 자동 추가 |

# 유성선병원 성형외과 홍보 웹사이트

> 대학병원의 안전함에 섬세함을 더한 유성선병원 성형외과 공식 홍보 사이트

**배포 URL**: [https://chul1215.github.io/ysmc_pla/](https://chul1215.github.io/ysmc_pla/)

---

## 기술 스택

- **Frontend**: 순수 HTML5, CSS3, Vanilla JavaScript (프레임워크/패키지 없음)
- **폰트**: Pretendard (CDN) → Apple SD Gothic Neo → Malgun Gothic
- **배포**: GitHub Pages (main 브랜치 푸시 시 자동 배포)
- **로컬 실행**: 파일 더블클릭으로 바로 열기 가능
